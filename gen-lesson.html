✍️ Build a detailed generation prompt for any lesson

Pick a lesson from the course, choose what kind of content it needs, set your accessibility and color requirements, and this tool assembles one detailed, ready-to-paste prompt you can hand to an AI assistant to draft that lesson's HTML page — in the same format, structure, and navigation pattern as the course's lesson template.

Every generated prompt still requires faculty subject-matter review before content reaches students, per the course's Safeguards & Responsible Use policy.

1 Choose a lesson & content types
2 Set accessibility, color, and page features
3 Generate, copy, and paste into your AI assistant

Format: URL | optional label — e.g. https://www.cisa.gov/... | CISA ICS Advisory. These get cited/linked as supporting resources in the lesson.

Format: filename or URL | optional caption. A bare filename is treated as sitting alongside the lesson HTML in the same folder; these become labeled download links.

Format: filename or URL | optional alt text / caption. A bare filename is treated as sitting alongside the lesson HTML in the same folder; these become inline, responsive <img> elements with real alt text.
