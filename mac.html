🎯 MAC Address Fundamentals

What is a MAC Address?

A Media Access Control (MAC) address is a unique 48-bit identifier assigned to network interface controllers (NICs). It operates at Layer 2 (Data Link Layer) of the OSI model and ensures unique identification of devices within a network segment.

🏢 IEEE Standards (2025)

  • IEEE 802.3: Ethernet standards
  • IEEE 802.11: Wi-Fi specifications
  • IEEE 802c-2017: SLAP (Structured Local Address Plan)
  • IEEE 802.1AE: MACsec encryption

📊 Allocation Sizes

  • MA-L (Large): ~16 million addresses
  • MA-M (Medium): ~65K addresses
  • MA-S (Small): ~4K addresses

🔐 Key Properties

  • 48-bit (6 bytes) length
  • Hexadecimal notation
  • Flat addressing structure
  • Non-routable across networks
  • Manufacturer assigned (usually)

🌐 Applications

  • Ethernet networking
  • Wi-Fi communications
  • Bluetooth connections
  • Network switching
  • Wake-on-LAN

⚠️ 2025 Privacy Trend: MAC Randomization

Modern devices increasingly use randomized MAC addresses to prevent tracking. This affects network management and requires new approaches for device identification and access control.

🔍 MAC Address Format & Analysis

MAC Address Structure

XX:XX:XX:YY:YY:YY

First 24 bits (OUI): Organizationally Unique Identifier - identifies manufacturer

Last 24 bits (NIC): Network Interface Controller specific - unique device identifier

🏷️ MAC Address Types

Unicast

LSB of first octet = 0
Identifies single device
Example: 00:1B:44:11:3A:B7

Multicast

LSB of first octet = 1
Group communication
Example: 01:00:5E:00:00:00

Broadcast

All bits set to 1
All devices in segment
FF:FF:FF:FF:FF:FF

Locally Administered

2nd LSB of first octet = 1
Software assigned
Example: 02:XX:XX:XX:XX:XX

⚙️ Protocol Operations

MAC Address Resolution Process (ARP)

Understanding how IP addresses are mapped to MAC addresses in local networks.

🔄 ARP Process

  1. Host needs to send packet to IP address
  2. Checks ARP cache for MAC address
  3. If not found, sends ARP request (broadcast)
  4. Target host responds with ARP reply
  5. Sender caches MAC address mapping
  6. Communication proceeds using MAC addresses

🌉 Switch Learning

  1. Frame arrives at switch port
  2. Switch examines source MAC address
  3. Updates MAC address table with port mapping
  4. Checks destination MAC in table
  5. Forwards to specific port or floods if unknown

🔒 Security Considerations

  • ARP Spoofing: Attackers can forge ARP responses
  • MAC Flooding: Overwhelming switch MAC table
  • MAC Cloning: Duplicating legitimate MAC addresses
  • Privacy: MAC addresses can be used for tracking

💼 Workplace Applications

🖨️ DHCP Reservations

Assign fixed IP addresses to specific devices using MAC addresses.

# Windows Server DHCP Add-DhcpServerv4Reservation -ScopeId 192.168.1.0 ` -IPAddress 192.168.1.100 ` -ClientId "00-50-56-12-34-56" ` -Description "Main Printer" # Cisco IOS DHCP ip dhcp pool PRINTER host 192.168.1.100 255.255.255.0 client-identifier 0100.5056.1234.56

⚡ Wake-on-LAN

Remotely power on devices using their MAC addresses.

# PowerShell Wake-on-LAN $mac = "00-50-56-12-34-56" $bytes = $mac.Split('-') | ForEach-Object {[byte]"0x$_"} $packet = (,0xFF * 6) + ($bytes * 16) $udp = New-Object System.Net.Sockets.UdpClient $udp.Send($packet, 102, "192.168.1.255", 9) # Linux wakeonlan command wakeonlan 00:50:56:12:34:56
