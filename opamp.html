📈 Interactive Op-Amp Configuration Grapher

One op-amp, six circuits, live dual-trace display: grey = input, green = output. Pick a configuration, shape the input, turn the resistor knobs, and watch the gain equations and calculus behaviors happen in real time — including clipping when you ask for more than the ±12 V rails can give.

💡 Guided Explorations
1. Read the resistors (Inverting): set Rf=20k, Rin=10k, sine input — confirm gain −2 and the 180° flip. 2. The "+1" (Non-Inv): same resistors — output is now ×3, not ×2, and upright. 3. Meet the rails: raise gain or amplitude until the green trace flattens at ±12 V; that haircut is clipping. 4. Unity on purpose (Follower): output hugs the input exactly. 5. Decisions (Comparator): sine in, slide VREF and watch the output's duty cycle change as the slice level moves. 6. Calculus (Integrator/Differentiator): square → integrator = triangle; triangle → differentiator = square; square → differentiator = edge spikes.
