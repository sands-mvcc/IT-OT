IPv6 Protocol Overview

Key Benefits of IPv6

IPv6 (Internet Protocol version 6) is the latest version of the Internet Protocol, designed to replace IPv4. With 128-bit addresses providing 340 undecillion possible addresses, IPv6 solves the address exhaustion problem of IPv4.

IPv6 vs IPv4 Comparison:
IPv4: 32-bit addresses (4.3 billion addresses)
IPv6: 128-bit addresses (340 undecillion addresses)
IPv4 Header: Variable length (20-60 bytes)
IPv6 Header: Fixed length (40 bytes)

IPv6 Header Structure

The IPv6 header has a fixed length of 40 bytes and contains 8 fields compared to IPv4's variable-length header.

Version (4 bits)
Traffic Class (8 bits)
Flow Label (20 bits)
Payload Length (16 bits)
Next Header (8 bits)
Hop Limit (8 bits)
Source Address (128 bits)
Destination Address (128 bits)

Header Field Explanations

Version: 4-bit field indicating the IP version, always 6 for IPv6

Traffic Class: 8-bit field for QoS marking, similar to IPv4 ToS field

Flow Label: 20-bit field to identify packet flows between source and destination

Payload Length: 16-bit field specifying the length of the payload following the IPv6 header

Next Header: 8-bit field identifying the type of header following the IPv6 header

Hop Limit: 8-bit field decremented by each router, packet discarded when reaching 0

IPv6 Address Compression Trainer

Address Compression Rules

IPv6 compression rules allow shortening of addresses by removing leading zeros and replacing consecutive zeros with "::"

Rule 1: Remove Leading Zeros
Before: 2001:0db8:0000:0042:0000:8a2e:0370:7334
After: 2001:db8:0:42:0:8a2e:370:7334
Rule 2: Replace Consecutive Zeros with "::" (only once)
Before: 2001:db8:0:0:0:0:370:7334
After: 2001:db8::370:7334

Security Implementation

IPv6 Firewall Rules

IPSec integration is built into IPv6 through extension headers

# ip6tables Firewall Rules # Allow established connections ip6tables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT # Allow ICMPv6 ip6tables -A INPUT -p ipv6-icmp -j ACCEPT # Allow SSH from management network ip6tables -A INPUT -s 2001:db8:1000:admin::/64 -p tcp --dport 22 -j ACCEPT # Block link-local from WAN ip6tables -A INPUT -i eth0 -s fe80::/10 -j DROP
