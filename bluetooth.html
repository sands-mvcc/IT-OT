Bluetooth Standards Overview

Bluetooth 6.0 (2024)

Latest Features:

  • Channel Sounding for centimeter-precision ranging
  • Decision-Based Advertising Filtering (DBAF)
  • Enhanced security with attack detection
  • IoT applications focus
Bluetooth 5.4 (2023)

Key Improvements:

  • Periodic Advertising Enhancement
  • Improved channel selection algorithm
  • Enhanced range and speed
  • Better reliability in crowded environments
Bluetooth 5.0-5.3

Major Features:

  • 4x range, 2x speed, 8x broadcast capacity
  • LE Audio support (5.2+)
  • LC3 codec for better audio quality
  • Mesh networking capabilities
Bluetooth LE (4.0+)

Low Energy Focus:

  • Ultra-low power consumption
  • Coin cell battery operation for years
  • IoT and beacon applications
  • 128-bit AES encryption

Bluetooth Security Architecture

Security Modes and Levels

Security Mode 1

Non-secure mode: No security procedures initiated

  • Level 1: No security
  • Level 2: Service-level security
  • Level 3: Link-level security
  • Level 4: Service & link security
Security Mode 2

Service-level security: Enforced after L2CAP channel establishment

  • Authorization required
  • Authentication optional
  • Encryption optional
  • Key size negotiable (1-16 bytes)
Security Mode 3

Link-level security: Enforced before physical link established

  • Mandatory authentication
  • Mandatory encryption
  • Fixed key size
  • Legacy security mode

Key Security Features:

  • Authentication: Challenge-response mechanism using shared secret keys
  • Authorization: Permission-based access to services and resources
  • Encryption: E0 stream cipher or AES-CCM for data protection
  • Key Management: Secure key generation, exchange, and storage
  • Secure Simple Pairing: ECDH-based key exchange (Bluetooth 2.1+)
