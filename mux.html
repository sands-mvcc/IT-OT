📈 Interactive Conversion & Routing Lab

Three instruments in one panel. Encoder → Decoder: press an input pad, watch its binary code form, and see the decoder light the matching output — the full round trip, with a priority-encoder toggle for multi-press conflicts. MUX → DEMUX: set data values, steer the select lines, and watch one shared channel carry the chosen signal to the chosen destination — then enable Auto-Scan for live time-division multiplexing. ADC → DAC: sample a real waveform, quantize it with your chosen bit depth, and compare the staircase reconstruction against the original.

💡 The canvas is clickable — input pads and switches respond directly.

💡 Guided Explorations
1. The round trip: in Encoder/Decoder mode press pad 5 — code reads 101, decoder output 5 lights. Try every pad and confirm the code is always the pad's binary name. 2. The conflict: priority OFF, press 3 and 4 together — the OR gates merge 011 and 100 into 111, a code claiming input 7 was pressed. It never was! Priority ON: 4 cleanly wins and the code is honest again. 3. Selection: in MUX/DEMUX mode set D2=1 (others 0), steer S1S0 to 10 — the channel goes live and Y2 lights; every other select code sends 0. 4. TDM: set D0=1, D1=0, D2=1, D3=0, enable Auto-Scan, and watch each value pop out of its own output in rotation — four signals sharing one wire. 5. The bit budget: in ADC/DAC mode set 1 bit — the staircase is a crude two-level caricature. Slide to 6 bits and watch it hug the wave. 6. Sampling matters too: at any resolution, stretch the sample interval and watch detail vanish between samples — resolution AND rate together set fidelity.
