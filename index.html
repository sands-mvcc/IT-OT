IT/OT Convergence Cybersecurity Faculty Development Workshop Executive Summary This comprehensive faculty development workshop addresses the critical and rapidly evolving field of IT/OT (Information Technology/Operational Technology) convergence in cybersecurity. As digital transformation accelerates across industries, the integration of traditional IT systems with operational technology creates both opportunities and significant security challenges. This workshop equips faculty with the knowledge, practical skills, and teaching materials needed to educate the next generation of cybersecurity professionals. Workshop Overview Duration: (2 days) Format: Online - Interactive, hands-on learning with theory and practical applications Target Audience: Community College faculty teaching cybersecurity, networking, or industrial technology courses Workshop Learning Outcomes By the end of this workshop, participants will be able to: 1. Define and Differentiate: Clearly articulate the differences between IT and OT systems and explain the significance of their convergence 2. Analyze Threats: Identify and assess cybersecurity risks specific to IT/OT converged environments 3. Apply Security Frameworks: Implement appropriate security controls and best practices for IT/OT environments 4. Design Practical Exercises: Create hands-on learning experiences using Cisco Packet Tracer for IT/OT scenarios 5. Teach Industry Cases: Effectively present real-world case studies from manufacturing, wastewater treatment, and logistics sectors 6. Core IT Devices • Servers Centralized systems for data processing, hosting applications, and managing network resources. • Desktops and Laptops End-user computing devices for daily business operations. • Tablets and Smartphones Mobile devices for communication, remote access, and productivity. • Workstations High-performance computers for specialized tasks such as design, engineering, or analytics. • Thin Clients Lightweight terminals that connect to centralized servers for processing. 2. Networking Devices and Technologies • Cabling and Communication Media Ethernet, Bluetooth, WIFI, 802.11, ZigbeeNet • Addressing MAC, IP, IPv6, TCP Ports • Routers Direct data traffic between networks and manage internet connectivity. • Switches Connect multiple devices within a local network for efficient data transfer. • Firewalls Protect networks by controlling incoming and outgoing traffic based on security rules. • Access Points Provide wireless connectivity for devices within a network. • Network Interface Cards (NICs) Hardware that connects computers to networks. 3. Core Network Services • Dynamic Host Configuration Protocol (DHCP) • Automatically assigns IP addresses to devices, simplifying network management and reducing configuration errors1. • Domain Name System (DNS) • Translates human-readable domain names into IP addresses, enabling seamless access to network resources1. • Network Time Protocol (NTP) • Synchronizes clocks across network devices, which is vital for accurate logging, troubleshooting, and security event correlation1. • Simple Network Management Protocol (SNMP) • Monitors and manages network devices, providing visibility into network health and performance. • File Transfer Protocol (FTP)/Secure FTP (SFTP) • Facilitates secure file transfers between devices and systems. • Hypertext Transfer Protocol (HTTP/HTTPS) • Enables web-based access to device interfaces, dashboards, and management tools. 4. Security and Access Services • IEEE 802.1X (Network Access Control) • Provides authentication for devices and users before granting network access, enhancing security1. • Virtual Private Network (VPN) Services • Secures remote access to OT and IT networks, supporting safe remote operations and maintenance. • Firewalls and Access Control Lists (ACLs) • Control and filter network traffic to protect critical assets and segment IT/OT environments. • Intrusion Detection/Prevention Systems (IDS/IPS) • Monitor network traffic for suspicious activity and help prevent cyber threats. 5. Device and Network Discovery • Cisco Discovery Protocol (CDP) and Link Layer Discovery Protocol (LLDP) • Identify and map network-connected devices, aiding in network management and troubleshooting1. • Network Telemetry (e.g., NetFlow) • Collects and analyzes network traffic data for performance monitoring and security analysis2. 6. affecting public health and safety Part 5 – Cybersecurity Control in IT/OT Converged Environments KPMG IT/OT Cybersecurity Convergence Framework This framework, based on leading standards (NIST SP 800-82, IEC 62443, ISO 27001, NERC CIP, etc.), defines nine key security domains for IT/OT convergence3: • Leadership & Governance: Risk management ownership and governance mechanisms • Security Operations: Proactive identification and prevention of cyber threats • Information Risk Management: Assessment and monitoring of information risks • Security Architecture: Secure design of information systems • Human Factors: Security culture, skills, and awareness • Technical Security: Implementation of technical controls to mitigate risks • Third Parties: Managing supplier and third-party risks • Compliance: Demonstrating adherence to regulatory and certification standards • Resilience: Ensuring the ability to defend and recover from cyberattacks These domains are tailored to the realities of IT/OT integration, emphasizing both technical and organizational controls. IEC 62443 and NIST SP 800-82 • IEC 62443: Focuses on industrial automation and control systems, with domains covering policies, procedures, technical requirements, and lifecycle management. • NIST SP 800-82: Provides guidance for securing industrial control systems, mapping controls to similar domains as NIST SP 800-171 but with OT-specific considerations.
